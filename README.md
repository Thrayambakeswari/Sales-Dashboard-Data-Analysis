# Sales-Dashboard-Data-Analysis
This project transforms static internet sales reports into interactive Power BI dashboards for tracking product and customer sales over time. It includes filters for sales reps, compares actuals to the 2021 budget, refreshes daily, and uses SQL and Excel data to support better decision-making and sales performance.
